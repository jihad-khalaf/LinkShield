# LinkShield — Minimal Flutter Sample

This repository contains a very small starter sample for the proposed LinkShield mobile application.

## Included
- `lib/main.dart`: a single-screen Flutter starter interface.
- `pubspec.yaml`: minimal Flutter project configuration.

## Note
This is a starter sample for the project proposal, not the completed URL analyzer.
The full application will be developed and tested in the next project stage.

## Run later
After installing Flutter, generate the platform folders with `flutter create .`,
then run `flutter pub get` and `flutter run`.
